# Adhil Haris — Portfolio

Single-page portfolio for Adhil Haris, Frontend Developer, built with React 19 and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Editing content

- Text, projects, experience and contact details: `src/data.js`
- Styles and palette: `src/index.css`
- Page sections: `src/App.jsx`, with components in `src/components/`
- Photo and CV: `public/photo.webp` and `public/resume.pdf`

## Deploy

Deploys as a static site (Vercel, Netlify or GitHub Pages). Run `npm run build` and publish the `dist/` folder.
